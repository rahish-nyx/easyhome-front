# Google Play Console — Content Rating (IARC)

Draft answers for the **Content Rating questionnaire** (Play Console → Policy → Content rating).

## Prelaunch questionnaire (suggested answers)

| Question | Answer |
| --- | --- |
| Violence / gore | None |
| Sexual content / nudity | None |
| Language | None |
| Alcohol / tobacco / drugs | None |
| Gambling | None |
| User-generated content (UGC) | Yes — bookings, reviews, support chats: moderated; harassment/abuse prohibited in terms |
| Privacy policy | Yes — provided in `PRIVACY_POLICY.md` / hosted URL |
| Online interactions | Yes — in-app support chat; professional–customer communication inside app; no open web chat |

## Final rating

**Expected IARC rating: Everyone (4+).**

Rationale:
- No violence, sexual content, language, drugs, gambling.
- UGC (reviews/chat) present but with terms prohibiting harassment — rated appropriate for all ages by content descriptors.
- Location and payments are age-appropriate (18+ contractual age for account creation per terms).

## Re-testing

- After submission, the developer fills the short form and may run an IARC test.
- If UGC descriptors change the rating, update here and in `PLAY_STORE_LISTING.md`.
