# Google Play Console — Ads Declaration

## Declaration

**The EasyHome apps do not currently serve ads and do not integrate any advertising SDK.**

- No ad SDK (AdMob, Meta Audience Network, Google AdMob, ironSource, AppLovin, etc.) is
  bundled in either APK.
- No ad inventory, mediation or attribution is used.
- Ad-related data is not collected.

If ads are added later, an `ads/app-ads.txt` declaration and the Advertising ID
declaration in the console must be updated.

## Console declaration

| Field | Value |
| --- | --- |
| Does the app contain ads? | No |
| Does the app use a third-party ad SDK? | No |
| Data collection for ads | Not applicable |
| Privacy policy link | Yes (see `PRIVACY_POLICY.md`) |
